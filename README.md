## Project Description

This repository houses solutions to various advanced algorithmic problems and technical interview challenges that are part of the ALX Software Engineering curriculum. Each subdirectory represents a distinct problem domain, showcasing implementations that balance both efficiency and readability.

The problems range from fundamental data structure manipulations to complex algorithmic puzzles designed to strengthen problem-solving abilities and prepare for technical interviews at top-tier technology companies.

## Projects Overview

| Project | Description |
|---------|-------------|
| [0x00-pascal_triangle](./0x00-pascal_triangle/) | Implementation of Pascal's Triangle algorithm |
| [0x01-lockboxes](./0x01-lockboxes/) | Solution to the lockboxes problem using graph traversal techniques |
| [0x02-minimum_operations](./0x02-minimum_operations/) | Algorithm to calculate minimum operations needed to achieve a result |
| [0x03-log_parsing](./0x03-log_parsing/) | Scripts for efficient log file parsing and analysis |
| [0x04-utf8_validation](./0x04-utf8_validation/) | Algorithm for validating UTF-8 encoding in byte sequences |
| [0x06-starwars_api](./0x06-starwars_api/) | JavaScript implementation for interacting with Star Wars API |
| [0x07-rotate_2d_matrix](./0x07-rotate_2d_matrix/) | In-place algorithm for rotating a 2D matrix |
| [0x08-making_change](./0x08-making_change/) | Dynamic programming solution to the coin change problem |
| [0x09-island_perimeter](./0x09-island_perimeter/) | Algorithm to calculate the perimeter of an island in a grid |
| [0x0A-primegame](./0x0A-primegame/) | Implementation of a strategic game based on prime numbers |

## Technologies

* Python 3.x
* JavaScript (Node.js)

## Setup and Usage

Each project directory contains:
- A README.md with specific problem descriptions and requirements
- Implementation files with the solution
- Test files to verify the correctness of the implementation

To run any solution:
1. Navigate to the specific project directory
2. Execute the main test file, e.g., `python3 0-main.py`

## Learning Objectives

- Implement efficient algorithms for complex problems
- Apply appropriate data structures to optimize solutions
- Analyze time and space complexity of algorithms
- Practice problem-solving techniques common in technical interviews
